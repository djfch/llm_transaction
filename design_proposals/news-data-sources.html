核心结论

三个数据源不是"选一个"，而是分工互补 —— 金十管宏观事件、律动管加密资金面、RSS 管英文一手原声。

主力 金十（宏观）

财经日历（当前自然周全量事件）+ 宏观快讯 + 深度文章 + 实时行情。数据已实测：本周日历含 8/7 美国非农、失业率（5 星）与 ADP（4 星），带实际值/预期值/前值/影响方向。

主力 BlockBeats（加密）

24h 全量快讯（约 50 条，正文全文+原文链接）+ ETF 资金流 + 稳定币市值 + 合约持仓量 + 情绪指标。实测当日快讯同时覆盖美联储鹰派、BTC 巨鲸、ETF 净流入——正是交易需要的因果链。

补充 RSS（英文一手）

补两个数据源的盲区：英文原声信源（美联储官网、彭博/路透原文）。中文媒体会转述、过滤、延迟，关键时刻值得直接读一手声明。

全面性评估：覆盖了什么，还缺什么

对"BTC/ETH 主流币 + 宏观驱动"这个场景的诚实评估。

✓ 已覆盖（够用）

  • 宏观事件时间表：本周非农/ADP/ISM/EIA 全在日历，带星级与预期
  • 宏观事件解读：金十+律动双快讯，数据公布后分钟级解读
  • 加密资金面：ETF 净流入、稳定币市值、合约持仓、情绪指标
  • 美元流动性锚：DXY、美债收益率、M2 均可直接取数
  • BTC/ETH 链上动态：巨鲸动向、链上数据、爆仓数据
  • 历史检索：两边均支持关键词搜索，可回溯历史新闻

✗ 缺口（需注意）

  • 英文一手信源：中文媒体为主，美联储声明/外媒原文需 RSS 补 → RSS 互补
  • 日历仅"当前自然周"：无法按指定日期/范围查询，跨周需自行累积存储 → 本地缓存
  • 24h 快讯 50 条封顶：爆量日（大跌/大事件）有截断风险 → 分页+搜索兜底
  • 无历史经济数据序列：日历是单条事件，拿不到 CPI 过去 12 期走势 → 逐周落库积累
  • 无原始财报/公告 PDF：事件详情需点原文链接跳转

数据流与存储设计

从"数据源"到"Agent 上下文"的完整链路：数据单向流动，新闻层不持有任何交易能力。

复用现有 scheduler：按频率触发拉取，记录 since_ts(上次拉取时间) 做增量，避免重复拉全量

▼
E

BTC/ETH 关键词 ∪ 高星事件(≥3) ∪ 近 2h 时间窗 —— 先把 95%+ 噪声挡在 LLM 之外

▼
F

摘要压缩 L2（LLM）

候选集压缩为 ≤10 条要点，按时间线排序，每条 ≤60 字

▼

6.2 存储设计（SQLite 三张表）

金额/数值字段沿用项目规范用 Decimal 语义存储（文本或整数最小单位），禁止 float。

表 1 · events 经济日历事件

字段说明约束
event_id事件唯一 ID（source + 标题 + 公布时间拼接）主键
source来源：jin10 / blockbeats索引
title事件名（如"美国7月非农就业人口"）
pub_time公布时间（本地时区 ISO）索引
star重要性 1-5 星
actual / consensus / previous实际值 / 预期值 / 前值（未公布为 NULL）
affect_txt影响方向：利多 / 利空 / 影响较小 / 未公布
fetched_at采集时间（便于过期判断）

表 2 · flash 快讯

字段说明约束
flash_id源 ID（金十/律动各自带 id）主键
sourcejin10 / blockbeats索引
title标题
content正文全文（过滤 HTML 标签后存储）
url原文链接
published_at发布时间索引
dedup_key标题 + 发布时间窗口哈希 —— 去重核心唯一

表 3 · indicators 指标快照

字段说明约束
id自增 ID主键
indicator指标键：etf_btc_netflow / dxy / us10y / m2 / stablecoin_usdt / sentiment / btc_oi…索引
value数值（Decimal 语义）
unit单位（亿美元 / % / 点…）
captured_at快照时间索引

指标表按时间累积成序列 —— 顺带解决"缺历史序列"的缺口，攒几周后就能画 ETF 流入趋势。

6.3 采集调度节奏（24h）

⚡

快讯增量每 5 分钟

金十 + 律动快讯，since_ts(上次拉取时间) 增量拉取，入库去重

📊

指标快照每 30 分钟

ETF 净流入 / DXY / 美债收益率 / M2 / 稳定币市值 / 情绪值，逐次落库成序列

📅

经济日历每小时

整点后刷新当前自然周日历，捕捉已公布事件的 actual(实际值) 回填

🌙

全量兜底每日 00:15

重拉 24h 快讯全量 + 日历全周，补齐增量拉取可能漏掉的缺口

🔥

5 星事件前后每 1 分钟

非农 / CPI / 议息等 5 星事件 ±30 分钟临时提速，快讯延迟压到 1 分钟内

🔔

事件告警（可选）

5 星事件公布瞬间，若 actual(实际值) vs consensus(预期值) 偏离超阈值，Telegram 推送
